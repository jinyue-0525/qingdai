# 轻待 QingDai

轻待是一款原生 macOS 菜单栏应用，用于管理待办事项，以及记录不同项目、不同地区的更新进度。使用 SwiftUI 和 AppKit 开发，数据保存在本机，无需账号或服务端。

## 功能

- **待办管理**：记录事项、备注、链接和标签，支持置顶、完成、稍后处理与重复任务。
- **提醒与快捷添加**：支持系统通知，默认全局快捷键为 `⌘⇧Space`，可在设置中切换或关闭。
- **项目与地区**：按项目、地区整理事项，保留未归属项目的普通待办。
- **更新台账**：按地区或按更新查看进度；各地区独立记录待更新、更新中、已更新、更新失败、不适用等状态，并保存备注、完成时间和历史。
- **数据与备份**：支持 JSON 导入导出、合并或替换恢复，以及自动备份。
- **菜单栏设置**：支持显示未完成数量、下一条待办或仅图标，并可设置开机启动。

## 环境要求

- macOS 14.0 或更新版本。
- 支持 Swift 5.9 或更新版本的 Xcode / Command Line Tools。
- 使用系统框架，无第三方包依赖。

## 从源码构建

```bash
git clone https://github.com/jinyue-0525/qingdai.git
cd qingdai
bash build.sh
```

脚本使用 Release 配置编译，生成图标、打包并进行本机临时签名。默认输出到项目目录的上一级：`../轻待.app`。

也可以指定输出目录：

```bash
QINGDAI_OUTPUT_DIR="$PWD/dist" bash build.sh
open "$PWD/dist/轻待.app"
```

应用运行后位于菜单栏，点击图标打开面板。生成的应用采用 ad-hoc 签名，未经过 Apple 公证；本仓库提供源码，不包含安装包。

## 使用更新台账

1. 在“更新台账 → 项目管理”中添加项目和地区。
2. 为项目创建更新，选择涉及的地区。
3. 在“按地区”或“按更新”视图中维护各地区的状态和备注。
4. 如需查看已经完成的记录，在筛选中开启“显示已更新及不适用”。

## 本地数据

数据目录为：

```text
~/Library/Application Support/QingDai/
├── tasks.json    # 待办、项目、地区和更新台账
└── Backups/      # 自动备份与恢复前备份
```

可通过应用设置中的“数据与备份”导入、导出或恢复记录。更新或迁移应用前，建议先导出备份。个人数据、备份、构建产物和本地配置不会随源码提交。
